# AValAnCHE fuzzers

This directory contains files to set up pluggable AValAnCHE fuzzers (test case
generators) using Docker. Exactly one fuzzer is expected to be running at any
time.

The most interesting options are:

- `grammarinator`: Uses grammar-based generation.
- `xsmith`:

The following fuzzers generate inputs very quickly, but are unlikely to trigger
interesting behavior in VerCors.

- `radamsa`: Uses the Radamsa blind fuzzer based on a small corpus of PVL files.
- `direct`: Returns the seed value as-is.


## Adding another fuzzer

All fuzzers are built as Docker containers so that development tools for the
implementation languages (Python, Racket, C and Python, respectively) do not
have to be installed. All speak the same simple "HTTP" API:

The fuzzers should accept a HTTP GET request on port 10070 with a seed value
(in this case generated by the Jazzer coverage-based fuzzer) encoded in base
64 (url-safe), as follows:

```
GET /?ZXhhbXBsZQ== HTTP/1.0
```

The seed value may be arbitrarily long (or empty). The fuzzer may ignore the
seed value if preferred.

In any case, the fuzzer should then return some test input.
